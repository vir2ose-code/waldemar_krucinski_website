# vir2ose Official Website & Portfolio
Offizielle Website von **Waldemar Krucinski (vir2ose)** – Songwriter, Tonstudio und Musikproduktionen Hannover.

## 🌐 Live Domains & Ecosystem
- **Hauptseite:** [waldemar-krucinski.com](https://www.waldemar-krucinski.com)
- **Plugin Store:** [plugins.waldemar-krucinski.com](https://plugins.waldemar-krucinski.com)
- **Web Radio:** [radio.waldemar-krucinski.com](https://radio.waldemar-krucinski.com)

## 🚀 Features
- **Design:** Modernes Dark-Studio / Gold Design mit Glassmorphism-Effekten.
- **Audio Engine:** Custom Web-Audio-Player mit Realtime-Visualizer und Playlist aller 5 Releases.
- **Video Grid:** Responsive Einbindung von 10 offiziellen YouTube-Releases.
- **Galerie:** Interaktive Lightbox für Studio- & Equipment-Bilder.
- **Partner Hub:** Direkte Vernetzung zu Spotify, Apple Music, Deezer, Tunecore, Distrokid, Rockpiano, ReMiK und Fiverr.
- **Performance:** 100% statisch, extrem schnell, ohne Fremd-Tracker oder Baukasten-Ballast.

## 📦 Deployment auf Vercel
1. Repository auf GitHub pushen.
2. In Vercel als neues Projekt importieren (Framework Preset: Other / Static HTML).
3. Eigene Domain `waldemar-krucinski.com` hinzufügen.
